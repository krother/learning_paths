
# Outline for an AI Lecture Series

## Generic Structure

I recommend the following structure for *each* lecture:

a) Python warmup typing
b) priming warmup exercise
c) theory
d) exercises
e) maybe c+d for a second, shorter topic
f) go through 5 exam questions
